# Arvore-busca-binária

Aluno: João Marcos

Descrição do projeto: O projeto implementa uma árvore de busca binária utilizando Java.

Implementação: A classe Node guarda o valor de cada nó e indica os nós da esquerda e da direita. A classe Tree organiza os valores inseridos e conta quantas folhas existem na árvore. A classe Main faz os testes, inserindo valores e mostrando a quantidade de folhas encontradas.

Exemplo: Foram inseridos os valores 50, 30, 70, 20, 40, 60 e 80.

Resultado: Quantidade de folhas: 4
